### 📦 Inventory & Purchase Order System

The system is currently being expanded with an inventory and procurement
module designed to improve control over clinic purchasing.

Instead of allowing inventory purchases to happen without a clear authorization
trail, the workflow introduces formal Purchase Orders and approval.

```text
┌──────────────────────┐
│    Purchase Request  │
│       from Staff     │
└──────────┬───────────┘
           │
           ▼
┌──────────────────────┐
│   Purchase Order     │
│      Generated       │
└──────────┬───────────┘
           │
           ▼
┌──────────────────────┐
│      Approval        │
└──────────┬───────────┘
           │
           ▼
┌──────────────────────┐
│    Approved PO       │
│   Sent to Vendor     │
└──────────┬───────────┘
           │
           ▼
┌──────────────────────┐
│  Goods / Inventory   │
│      Received        │
└──────────┬───────────┘
           │
           ▼
┌──────────────────────┐
│   Vendor Invoice     │
└──────────┬───────────┘
           │
           ▼
┌──────────────────────┐
│ PO + Bill + Inventory│
│     Verification     │
└──────────────────────┘
```

The objective is to create traceability between:

`Request → Approval → PO → Vendor → Inventory → Invoice → Audit`

This allows the clinic to verify what was requested, who approved it, what was
ordered, what was received, and whether the resulting vendor bill corresponds
to an authorized purchase.

### Technology

`Java` `Spring Boot` `Firebase` `Thymeleaf` `Maven`
